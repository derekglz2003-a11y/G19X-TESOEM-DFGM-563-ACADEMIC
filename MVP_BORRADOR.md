# MVP — CurriculAI (borrador)

**Incluye:** panel Streamlit, API FastAPI, persistencia SQLAlchemy, gestión de vacantes y candidatos, extracción de CV, ranking semántico local, entrevistas y finalistas.

**Dependencias externas opcionales:** Gemini para extracción y generación de descripciones; UltraMsg para notificaciones.

**Prueba mínima:** iniciar backend y frontend; crear vacante; cargar CV con texto; evaluar; revisar Top 5; crear entrevista; eliminar expediente de prueba.

**No validado automáticamente:** servicios externos, calidad del ranking, funcionamiento en Windows, integración con la base de datos real y políticas de protección de datos.
